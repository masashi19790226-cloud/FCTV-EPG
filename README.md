# FCTV番組表 v2

CableGateのWeb画面を表示せず、Gガイドの公開番組データを取得してAndroid側で番組表を表示するプロトタイプです。

- 列：テレビ局・チャンネル
- 行：時間
- 番組の開始時刻から終了時刻までを番組枠として表示
- 地上波 / BS / CATV の3タブ
- BS10を含むBSチャンネル
- CATVではコミュニティ系チャンネルを除外
- 日付移動・今日・更新・引っ張って更新
- ピンチ拡大縮小、拡大率保存
- 横スクロール＋縦スクロール

Gガイドの`line` / `time[s]` / `program_title`構造を使って、1日分の番組をチャンネル単位で取得します。

注意：GガイドのHTML構造変更やアクセス制限により取得できない場合があります。CATVのチャンネル構成はFCTV側のサービス変更に合わせて今後調整します。
