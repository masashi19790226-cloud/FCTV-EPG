# FCTV番組表 v2.3

- 地上波 / BS / CATV のタブ
- 列=テレビ局、行=時間
- 番組の開始時刻から次番組までを枠の高さに反映
- 横スクロール / 縦スクロール / ピンチズーム
- 拡大率を保存
- 日付移動、今日、更新、引っ張って更新
- Androidのステータスバー・ナビゲーションバーとの重なりを回避
- エラー文字をタイトル行に表示せず、番組表領域に表示
- Gガイドの現在のDOM変更に備え、time[s]から親要素をたどってチャンネルを判定

注意: GガイドのWebページを直接取得する方式は、ページ側の仕様変更やアクセス制限で取得できなくなる可能性があります。FCTVの公式EPGはSTBで8日分が表示でき、契約内容により表示チャンネルが異なります。
